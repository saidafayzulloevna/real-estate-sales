# Сарой — веб-лоиҳаи агентии амволи ғайриманқул

Сайти намоишӣ бо забони тоҷикӣ барои ҷустуҷӯи хона, ҳавлидор ва қитъаи замин. Барои кори лоиҳавӣ/таълимӣ омода шудааст.

## Имкониятҳо

- Тарҳи мутобиқшаванда барои телефон ва компютер
- Рӯйхати намунавии амвол бо аксҳо ва маълумоти асосӣ
- Филтр аз рӯи навъи амвол, минтақа ва нарх
- Равзанаи маълумоти муфассали эълон
- Илова ва хориҷ кардани эълонҳо аз дӯстдоштаҳо
- Шакли дархост бо тасдиқи намоишӣ
- Менюи мобилӣ

## Иҷро

Файли `index.html`-ро дар браузер кушоед. Барои таҳрир, папкаро дар Visual Studio Code кушоед.

## Нашр дар GitHub Pages

1. Дар GitHub репозитории нави `realty-agency` созед.
2. Файлҳои дохили ин папкаро ба репозиторий илова кунед.
3. Ба **Settings → Pages** гузаред.
4. Дар **Build and deployment** манбаи **Deploy from a branch**-ро интихоб кунед.
5. Branch-и `main` ва папкаи `/ (root)`-ро интихоб карда **Save**-ро пахш кунед.
6. Баъди чанд дақиқа GitHub Pages пайванди сайтро нишон медиҳад.

> Эълонҳо, рақами телефон, суроғаҳо ва нархҳо барои намоиш сохта шудаанд. Шакли тамос ҳоло маълумотро ба сервер намефиристад; барои истифодаи воқеӣ backend ё хидмати шакл лозим мешавад.
